# 中药材行业行情数据平台 - 设计文档

## 1. 项目概述

### 1.1 项目定位
数据驱动的中药材行业行情平台，以价格数据可视化与智能分析为核心竞争力，覆盖全产业链用户（产地农户、药材商户、药厂企业、终端用户），差异化于现有中药材天地网和药通网。

### 1.2 参考竞品
- 中药材天地网 (zyctd.com)：价格数据全面，溯源系统，但图表功能弱
- 药通网 (yt1998.com)：资讯丰富，供求信息完善，但缺乏数据可视化

### 1.3 核心差异化
1. **ECharts 交互式图表**：K线图、面积图、多品种叠加对比，远超竞品的简单表格
2. **Leaflet 产地地图**：热力图展示全国产地价格分布，竞品无此功能
3. **综合价格指数**：类似大盘指数的中药材行业指数，竞品无此功能
4. **数据增值服务**：深度分析报告、数据导出，匹配免费+增值盈利模式

### 1.4 项目策略
- MVP 先行，快速上线验证
- 爬虫采集为主的数据来源策略
- 免费+增值服务盈利模式
- Spring Boot 单体起步，未来拆微服务

## 2. 技术架构

### 2.1 技术栈

| 层级 | 技术选型 | 说明 |
|------|---------|------|
| 前端 | Vue 3 + Vite + Element Plus | PC 端管理后台与用户端 |
| 状态管理 | Pinia | Vue 3 官方推荐状态管理 |
| 图表 | ECharts 5 | 价格走势、K线、热力图、雷达图 |
| 地图 | Leaflet | 产地分布地图、价格热力图 |
| 移动端 | Uni-app (Vue 3) | 编译 iOS/Android/微信小程序 |
| 后端 | Java Spring Boot | 单体应用，REST API |
| 爬虫 | Python (Scrapy/Requests) | 独立服务，定时采集 |
| 数据库 | MySQL 8.0 | 业务数据存储 |
| 缓存 | Redis 7 | 实时价格缓存、会话管理 |
| 搜索 | Elasticsearch 8 | 品种搜索、资讯全文检索 |
| 反向代理 | Nginx | 静态资源、API 转发、负载均衡 |

## 3. 功能板块与页面设计

|------|--------|-----------|---------|

### 3.2 价格中心

#### 3.2.1 市场价格列表页
- **路由**：`/price/market`
- **功能**：
  - 按市场筛选（亳州、安国、成都、玉林、廉桥、普宁）
  - 按品种分类筛选（根茎类、果实类、全草类、花类、叶类、皮类、藤木类、树脂类、菌藻类、动物类、矿物类、其他）
  - 搜索框支持品种名称/拼音首字母
  - 表格列：品种名、规格、产地、今日价、日涨跌、月涨跌、走势迷你图
  - 涨跌颜色标识（红涨绿跌）
  - 点击品种名进入详情页
- **数据来源**：爬虫采集 + Redis 缓存

#### 3.2.2 产地价格列表页
- **路由**：`/price/origin`
- **功能**：
  - 按省份/产区筛选
  - 表格列：品种名、规格、产地、今日价、月涨跌、走势迷你图
  - 右侧关联产地地图缩略图
- **数据来源**：爬虫采集

#### 3.2.3 品种价格详情页
- **路由**：`/price/detail/:herbId`
- **功能**：
  - 品种基本信息（名称、别名、科属、性味归经）
  - 当前价格概览（各市场/规格价格卡片）
  - ECharts 历史价格走势图（支持日/周/月/年切换，支持面积图/K线图切换）
  - 涨跌统计（日/周/月/年涨跌幅、最高/最低价）
  - 不同市场价格对比柱状图
  - 关联资讯列表
  - 关联供求信息
  - "加入关注"按钮
- **免费/付费**：基础走势图免费，3年以上历史数据+高级分析付费

#### 3.2.4 涨跌排行榜页
- **路由**：`/price/ranking`
- **功能**：
  - Tab 切换：日涨跌 / 周涨跌 / 月涨跌
  - 涨幅榜 Top20 + 跌幅榜 Top20
  - ECharts 横向柱状图可视化
  - 涨跌品种数量饼图概览
- **数据来源**：Redis 实时计算

#### 3.2.5 价格对比页
- **路由**：`/price/compare`
- **功能**：
  - 选择 2-5 个品种进行价格走势叠加对比
  - ECharts 多系列折线图
  - 归一化对比（以起始价格为基准 100）
  - 品种基本信息对比表格
- **免费/付费**：付费功能

### 3.3 行情资讯

#### 3.3.1 资讯列表页
- **路由**：`/news/list`
- **功能**：
  - 分类 Tab：全部 / 品种分析 / 药市动态 / 集采资讯 / 采购招标
  - 列表卡片：标题、摘要、发布时间、关联品种标签、阅读量
  - 分页加载
- **数据来源**：爬虫采集 + 编辑录入

#### 3.3.2 资讯详情页
- **路由**：`/news/detail/:newsId`
- **功能**：
  - 标题、作者、发布时间、阅读量
  - 富文本内容（图文混排）
  - 关联品种价格链接（点击跳转品种详情）
  - 上一篇/下一篇导航
  - 相关资讯推荐

#### 3.3.3 每日行情简报页
- **路由**：`/news/daily`
- **功能**：
  - 日期选择器
  - 当日涨跌品种汇总
  - 市场要闻摘要
  - 重点品种点评

### 3.4 供求大厅

#### 3.4.1 供应信息列表页
- **路由**：`/supply/list`
- **功能**：
  - 筛选：品种 / 产地 / 规格 / 发布时间
  - 列表卡片：品种名、规格、产地、数量、价格（明码/电议）、发布时间
  - 联系方式（登录后可见）

#### 3.4.2 求购信息列表页
- **路由**：`/demand/list`
- **功能**：
  - 筛选：品种 / 规格 / 交货地 / 发布时间
  - 列表卡片：品种名、规格、需求数量、交货地址、已报价人数、剩余天数
  - "我要报价"按钮

#### 3.4.3 发布供求页
- **路由**：`/supply/publish` 或 `/demand/publish`
- **功能**：
  - 表单：品种选择（搜索+下拉）、规格、产地、数量、单位、价格类型（明码/电议）、价格、联系方式、图片上传
  - 发布需登录
  - 免费发布，置顶/推荐为付费增值

#### 3.4.4 企业采购页
- **路由**：`/procurement/list`
- **功能**：
  - 企业采购计划列表
  - 采购详情：企业名称、采购品种清单、截止日期、联系方式

### 3.5 数据中心

#### 3.5.1 产地地图页
- **路由**：`/data/map`
- **功能**：
  - Leaflet 中国地图
  - 热力图图层：按省份/地市展示价格涨跌热度
  - 标记点：主要产地标注，点击弹出产地详情（品种数、均价、涨跌）
  - 图层切换：价格热力 / 产量分布 / 品种分布
  - 左侧品种筛选面板

#### 3.5.2 价格指数页
- **路由**：`/data/index`
- **功能**：
  - 综合价格指数走势图（ECharts）
  - 分类子指数：根茎类指数、果实类指数等
  - 指数构成说明
  - 日/周/月/年切换

#### 3.5.3 品种对比分析页
- **路由**：`/data/compare`
- **功能**：
  - 多品种选择（2-5个）
  - 多维度对比：价格走势、产量趋势、产地分布
  - 雷达图对比（价格波动率、供需指数、关注度等）
  - 对比报告生成
- **免费/付费**：付费功能

#### 3.5.4 数据导出页
- **路由**：`/data/export`
- **功能**：
  - 选择品种、时间范围、数据类型
  - 导出格式：CSV / Excel
  - 导出记录
- **免费/付费**：付费功能

### 3.6 药材百科

#### 3.6.1 药材列表页
- **路由**：`/herb/list`
- **功能**：
  - 分类浏览：按功效（解表/清热/泻下/祛湿/温里/理气/消食/止血/活血/化痰/止咳/平肝/安神/开窍/补虚/收涩/涌吐/攻毒/拔毒）、按药用部位、按拼音首字母
  - 搜索框
  - 列表：名称、别名、科属、性味、功效摘要

#### 3.6.2 药材详情页
- **路由**：`/herb/detail/:herbId`
- **功能**：
  - 基本信息：名称、别名、科属、性味归经、功效、主治
  - 产地分布（关联产地地图）
  - 规格等级说明
  - 种植技术要点
  - 关联当前价格（链接到价格详情）
  - 关联资讯

#### 3.6.3 种植技术页
- **路由**：`/herb/planting`
- **功能**：
  - 按品种分类的种植技术文章列表
  - 文章详情：选地整地、繁殖方法、田间管理、病虫害防治、采收加工

- **功能**：

  - 会员套餐展示（月度/季度/年度）

#### 3.7.5 我的发布页
- **路由**：`/user/publishments`
- **功能**：

## 7. 爬虫服务设计

### 7.1 爬虫目标
- 天地网价格数据（市场价格 + 产地价格）
- 药通网价格数据（市场价格 + 历史价格）
- 药通网资讯数据
- 天地网资讯数据

### 7.2 爬虫架构
- 框架：Scrapy + APScheduler
- 调度策略：
  - 价格数据：每日 8:00 / 12:00 / 18:00 各采集一次
  - 资讯数据：每 2 小时采集一次
  - 历史数据：首次全量采集，后续增量
- 数据清洗：pandas 标准化品种名称、规格、产地
- 入库：通过 Spring Boot API 写入，或直接写入 MySQL
- 反爬策略：请求间隔随机化、User-Agent 轮换、代理 IP 池

### 7.3 数据标准化
- 品种名称映射表（不同网站同一品种名称可能不同）
- 规格标准化（统货/选货/一级/二级等）
- 产地标准化（省/市/县 三级地址标准化）
- 市场映射（亳州/安国/成都/玉林/廉桥/普宁）

## 10. 非功能性需求

### 10.1 性能
- 首页加载时间 < 2s
- API 响应时间 < 500ms（P95）
- 价格列表支持 1000+ 品种分页加载
- ECharts 图表渲染 < 1s

### 10.2 安全
- JWT Token 认证，Token 有效期 2 小时
- 短信验证码 60s 间隔限制
- 接口限流：普通用户 100次/分钟，会员 500次/分钟
- SQL 注入防护、XSS 防护
- 敏感数据加密存储

### 10.3 SEO
- SSR 或预渲染关键页面（首页、品种详情、资讯详情）
- 结构化数据标记（Schema.org）
- Sitemap 自动生成
- 品种名称 + 拼音 URL 友好

### 10.4 监控
- Spring Boot Actuator 健康检查
- 爬虫任务执行状态监控
- 价格数据异常检测（涨跌超过阈值告警）
- API 调用统计
